Anonymous Product Rating

Let anonymous visitors rate and review your products — securely, without an account.
Odoo 17 Community Website eCommerce

Overview

The Anonymous Product Rating module lets non-logged-in visitors rate and review products directly on your Odoo website — no registration required. It was built for stores that want social proof and customer feedback without forcing visitors to create an account.
Anonymous ratings are stored in a dedicated model, kept separate from Odoo's core rating system, and then merged with registered-user ratings into a single unified rating display. The module ships with strong bot protection: reCAPTCHA v3 integration, multi-layer rate limiting, spam detection, content sanitization, and request validation — so your ratings stay genuine and your site stays safe.

Key Features

Anonymous Rating System

Visitors rate products (1–5 stars) and optionally leave a review, without creating an account.

Unified Rating Display

Combines anonymous and registered-user ratings into one average and count, shown across your whole shop.

Bot & Spam Protection

reCAPTCHA v3 score validation, user-agent analysis and pattern-based spam detection.

Multi-Layer Rate Limiting

Per-IP, per-name and per-email submission limits with configurable time windows.

Flexible Moderation

Auto-publish ratings or review each submission manually; bulk approve/reject from the backend.

Review Images

Visitors can attach up to 3 images to their review, with automatic thumbnail generation.

Content Security

XSS sanitization, script injection filtering, character limits and input validation on every request.

Monitoring & Analytics

Performance monitor transients, moderation statistics, security incident logging and health endpoints.

Installation & Configuration

  1. Copy the anonymous_product_rating folder into your Odoo addons directory.
  2. Update the Apps list in Odoo (Developer mode → Update Apps List).
  3. Install the Anonymous Product Rating app. It depends on website_sale and rating.
  4. Go to Website → Configuration → Settings to configure auto-publish, rate limits and moderation.
  5. (Optional) Configure reCAPTCHA v3 keys under General Settings → reCAPTCHA for stronger bot protection.
